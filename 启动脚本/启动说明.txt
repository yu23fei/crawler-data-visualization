招聘大数据可视化分析平台 —— 启动说明
========================================

本文件夹集中放置了项目的启动脚本，双击即可运行。

【首次运行前，需要做的准备】

1. 安装后端依赖（只需一次）：
   在项目根目录打开命令行，执行：
       pip install -r requirements.txt

2. 配置数据库（只需一次）：
   把项目根目录的 .env.example 复制为 .env，
   编辑 .env 填入你的数据库密码、JWT 密钥等信息。

   注意：需要本机 MySQL 服务已启动，
   且数据库账号能正常连接（默认 root / 你的密码）。

3. 安装前端依赖（只需一次）：
   双击「启动前端.bat」会自动执行 npm install，
   或者手动在 frontend 目录执行：
       npm install

【启动方式】

  方式一（推荐）：双击「一键启动全部.bat」
      会自动开两个窗口，分别启动后端和前端。

  方式二：分开启动
      - 双击「启动后端.bat」  → 启动后端 http://localhost:5000
      - 双击「启动前端.bat」  → 启动前端 http://localhost:3000

【访问】

  浏览器打开：http://localhost:3000
  （前端会自动把 /api 请求代理到后端 5000 端口）

【停止】

  关闭对应的命令行窗口即可停止服务。

【常见问题】

  Q: 后端提示「DB_PASSWORD 未设置」？
  A: 说明 .env 没配置或没放对位置，请按上面第 2 步配置。

  Q: 前端报「Cannot find module」？
  A: node_modules 没装好，删除 frontend\node_modules 后重新启动前端。

  Q: 数据库连不上？
  A: 确认 MySQL 已启动，且 .env 里的账号密码正确。
